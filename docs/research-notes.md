## Corrected mathematical notes

### Sphere volume

For a normal 3D sphere:

```text
V = 4/3 · π · r^3
```

Not `4/3 · π · r^4`.

If `r^4` appears, that belongs to higher-dimensional or different formulas, not ordinary 3D sphere volume.

### Weighted voltage / weighted color analogy

The formula:

```text
V = (E1/R1 + E2/R2 + E3/R3) / (1/R1 + 1/R2 + 1/R3)
```

is a conductance-weighted average. It can be used as an analogy for weighted RGB mixing if applied per color channel:

```text
R_out = weighted_average(R1, R2, R3)
G_out = weighted_average(G1, G2, G3)
B_out = weighted_average(B1, B2, B3)
```

It should not be treated as a full color science model by itself.
